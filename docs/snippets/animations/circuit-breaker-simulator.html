Interactive simulatorDrive a circuit breaker yourself

Settings are scaled down so you can watch a full cycle in seconds: a COUNT_BASED window of 10 calls, minimumNumberOfCalls 5, waitDurationInOpenState 5 s, permittedNumberOfCallsInHalfOpenState 3, automatic OPEN → HALF_OPEN. Try Dependency goes down, wait for HALF_OPEN, then Dependency recovers, or set the failure rate near the threshold and watch it flap.

This simulator needs JavaScript. In the online handbook you can set the dependency's failure rate and the failureRateThreshold, send traffic, and watch the breaker move between CLOSED, OPEN and HALF_OPEN: calls recorded in a sliding window, fast failures with CallNotPermittedException while OPEN, and a few trial calls deciding whether HALF_OPEN closes or reopens.
